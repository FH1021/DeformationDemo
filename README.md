# 全局变形演示程序

一个基于 Electron + three.js 的 3D 全局变形交互演示工具，支持 **锥化、扭曲、弯曲、FFD 自由变形** 四种变形方式，可导入外部 OBJ 模型并实时预览变形效果。程序界面为全中文，适合计算机图形学课程演示与实验。

---

## 功能特性

- **四种全局变形**：锥化（Taper）、扭曲（Twist）、弯曲（Bend）、FFD 自由变形（Free-Form Deformation）
- **OBJ 模型导入**：支持导入任意 Wavefront OBJ 文本模型；内置圆柱、圆环两个示例模型
- **变形轴可配置**：自动（按包围盒最长边）或手动指定 X / Y / Z 轴
- **FFD 网格控制点拖拽**：在模型包围盒内生成 (n+1)³ 个网格控制点，直接鼠标拖拽观察实时变形
- **实时预览**：所有参数调节即时生效，无需等待
- **多视角查看**：左键旋转、右键平移、滚轮缩放
- **辅助显示**：可切换线框显示、包围盒显示；信息面板实时显示顶点数、三角形数、包围盒与变形轴

## 操作指南

### 界面布局

- 左侧：控制面板（模型加载、显示设置、变形参数、FFD 控制、信息统计）
- 右侧：3D 视口（模型、包围盒、坐标轴、网格地面）

### 模型操作

| 操作          | 说明                                            |
| ----------- | --------------------------------------------- |
| 点击「圆柱」/「圆环」 | 加载内置示例模型                                      |
| 点击「选择文件」    | 导入本地 OBJ 文件（UTF-8 文本，支持 `v` / `f` 等常见 OBJ 语法） |
| 左键拖拽        | 旋转视角                                          |
| 右键拖拽        | 平移视角                                          |
| 滚轮          | 缩放视角                                          |

### 显示选项

- **线框显示**：勾选后模型以线框形式显示
- **显示包围盒**：勾选/取消绿色包围盒线框
- **变形轴**：`自动（最长边）` 按包围盒最长边确定变形轴；也可手动选择 X / Y / Z。变形轴在信息面板中实时显示

### 全局变形

勾选对应复选框启用变形，拖动滑块调节强度：

| 变形 | 参数   | 范围           | 说明                                                      |
| -- | ---- | ------------ | ------------------------------------------------------- |
| 锥化 | 系数 k | -0.95 ~ 1.5  | 横向缩放系数 s = 1 + k·t（t 为沿轴归一化位置 0→1），k>0 时远离轴心端放大，k<0 时缩小 |
| 扭曲 | 角度   | -180° ~ 180° | 截面绕变形轴旋转，角度 θ = θmax·t，沿轴线性累积                           |
| 弯曲 | 角度   | -180° ~ 180° | 中性轴弯成圆弧，半径 R = 轴长 / θmax，模型呈弯曲弧状                        |

- 「重置全局变形」：清除锥化/扭曲/弯曲参数
- 「全部重置」：恢复所有参数为默认值，并重建 FFD 网格

### FFD 自由变形

1. 勾选「启用 FFD（拖拽控制点）」，模型表面出现黄色控制点与半透明网格线
2. 调节「网格密度 n」（1 ~ 6，默认 2，即 27 个控制点），网格越密变形越精细、控制点越多
3. **点击任意黄色控制点并拖拽**，模型随控制点移动实时变形
4. 「重置控制点」：将所有控制点恢复至包围盒均匀分布位置

> 拖拽时模型会暂时跟随控制点所在平面移动，松开鼠标后恢复视角控制。

## 变形算法说明

程序以模型原始顶点为输入，按 **锥化 → 扭曲 → 弯曲 → FFD** 的顺序叠加变形，每个顶点逐次变换。设变形轴为归一化高度 t（包围盒内 0 → 1），横向坐标为 (lat.a, lat.b)：

- **锥化**：`p[lat.a] *= s; p[lat.b] *= s`，其中 `s = 1 + k·t`
- **扭曲**：截面绕轴旋转 `θ = θmax·t`，对横向坐标做旋转变换
- **弯曲**：中性轴弯成圆弧，`R = h / θmax`，轴向与横向坐标按圆弧几何重排
- **FFD**：在包围盒内建立 (n+1)³ 网格点 `P(i,j,k)`，顶点新位置为  
  `Σ Bᵢ(s)·Bⱼ(t)·Bₖ(u)·P(i,j,k)`，其中 B 为 n 次 Bernstein（伯恩斯坦）基函数，参数 s/t/u 取自原始坐标的归一化位置；拖拽控制点即修改 P，模型随之变形

## 系统要求

- **Windows 10 / 11（64 位）**，或任意支持 WebGL 的现代浏览器（网页版）
- 显卡需支持 WebGL 1.0 及以上（集成显卡亦可流畅运行）
- 建议分辨率 1280 × 820 以上

## 从源码构建

### 环境准备

- 安装 [Node.js](https://nodejs.org/)（建议 18 LTS 及以上）

### 安装依赖并运行

```bash
cd global-deformation-demo-app
npm install          # 安装 electron、electron-packager 等依赖
npm start            # 以开发模式启动应用
```

### 重新打包 EXE

```bash
npx electron-packager . DeformationDemo --platform=win32 --arch=x64 --out=dist --overwrite --prune=true
```

打包结果位于 `dist/DeformationDemo-win32-x64/`，其中 `DeformationDemo.exe` 即可直接分发。
